학습마당 사용 안내

교육생이 실습 결과물을 올리는 보드입니다.
강사·튜터는 배정된 회차의 보드를 관리합니다.

접속 주소
b2b-board.spartaclub.kr

로그인

  1. 위 주소로 접속합니다.
  2. "강사 · 교육 담당자"를 누릅니다.
  3. axhub에 등록된 이메일을 입력합니다.비밀번호는 없습니다.
주의 보드 주소로 들어와도 같은 화면이 나옵니다.
"교육생"을 누르면 교육생으로 들어가게 되니 주의해 주세요.

axhub에서 회차에 배정되면 1시간 안에 그 회차 보드가 보입니다.

내 보드 찾기

교육 → 회차 → (분반) 순서로 들어갑니다.

  • 반을 나눈 회차는 담당 반을 고릅니다.
  • 회차에 속하지 않은 보드(Q&A 등)는 교육 화면 위쪽에 있습니다.
  • 여러 날 진행하는 회차도 보드는 하나입니다. 날짜별로 나누려면 섹션을 만들어 주세요.

URL 복사를 누르면 보드 주소가 복사됩니다.
주소가 숫자 7자리(b2b-board.spartaclub.kr/4820391)라 칠판에 적어도 됩니다.

수업 전 준비

  1. 담당 회차의 보드를 엽니다.보드가 안 보이면 운영 매니저에게 알려 주세요.
  2. 입장 비밀번호를 확인합니다.교육 화면 제목 옆 "입장 비밀번호"를 누르면 보입니다.
    보드 화면에는 나오지 않습니다.
  3. 교안 링크를 확인합니다.보통 자동으로 올라와 있습니다. 없으면 직접 올려 주세요.
  4. 필요한 섹션을 추가합니다.섹션 탭 끝의 "+ 섹션"을 누릅니다. 예: "1일차 실습", "프롬프트 공유"
  5. 교육생에게 보드 주소와 비밀번호를 알려 줍니다.비밀번호는 주소와 따로, 말이나 칠판으로 알려 주세요.
여러 회차를 맡았다면 한 보드를 정리한 뒤 "보드 관리 → 다른 회차로 복제"를 쓰세요.
섹션과 고정 게시물이 다른 회차 보드로 복사됩니다.

교육생 입장

교육생은 가입 없이 보드 주소로 들어옵니다.

  1. 보드 주소로 접속합니다.
  2. "교육생"을 누릅니다.
  3. 개인정보 동의 내용을 끝까지 내리고 "동의하기"를 누릅니다.
  4. 이름(실명)과 입장 비밀번호를 넣고 "참여하기"를 누릅니다.
  • 입장 비밀번호는 교육마다 하나입니다. 모든 회차·분반이 같습니다.
  • 같은 기기·같은 브라우저로 다시 오면 바로 들어옵니다.
  • 다른 기기나 시크릿 창으로 오면 새 사람으로 들어와, 전에 올린 글을 고칠 수 없습니다.
  • 공용 PC에 앞 사람 이름이 남아 있으면 오른쪽 위 이름 → "다른 사람으로 참여"를 누릅니다.

강사 기능

기능사용 방법
자료 올리기"자료 올리기"를 누르거나 파일을 보드에 끌어다 놓습니다. 파일당 300MB까지.
캡처 올리기캡처한 뒤 보드에서 Ctrl+V
상단 고정강사 글은 자동으로 맨 앞에 고정됩니다. 교육생 글은 카드 메뉴(…) → "상단 고정"
고정 순서 바꾸기고정된 카드를 끌어서 옮깁니다.
여러 장 한 번에"보드 관리 → 카드 여러 장 선택"에서 고정·해제·삭제
섹션 관리"보드 관리"에서 이름 변경·삭제. 섹션을 지우면 안의 글도 지워집니다.
글·댓글 삭제교육생 글도 카드 메뉴(…)에서 지울 수 있습니다.
다른 회차로 복제"보드 관리 → 다른 회차로 복제"
다른 회차 결과물보드 제목 옆 "다른 회차 결과물 보기". 같은 교육 모든 회차의 결과물을 모아 봅니다.

자주 묻는 질문

"등록되지 않은 이메일"이라고 나옵니다

axhub에 등록된 이메일인지 확인해 주세요.
배정 직후라면 최대 1시간 뒤에 반영됩니다. 급하면 운영 매니저에게 요청해 주세요.

교육생이 들어오지 못합니다
  • "비밀번호가 맞지 않아요" 대소문자와 특수문자까지 다시 확인해 주세요.
  • "잠시 막혔어요" 여러 번 틀린 경우입니다. 10분쯤 뒤에 다시 시도해 주세요.
  • "참여하기"가 안 눌림 동의 내용을 끝까지 내리고 "동의하기"를 먼저 눌러야 합니다.
  • "숫자를 다시 확인해 주세요" 보드 주소 7자리를 다시 확인해 주세요.
교육생이 자기 글을 고칠 수 없다고 합니다

글을 올릴 때와 다른 기기·브라우저로 들어온 경우입니다.
처음 쓴 기기로 다시 들어오게 해 주세요. 급하면 강사가 지우고 다시 올리게 하면 됩니다.

파일이 올라가지 않습니다

창에 쓴 내용은 남아 있으니 "다시 시도"를 눌러 주세요.
파일당 300MB까지 올릴 수 있습니다.

교안 링크가 없습니다

axhub에 교안이 등록되지 않은 교육입니다. 교안 섹션에 직접 올려 주세요.

입장 비밀번호를 바꾸고 싶습니다

강사는 바꿀 수 없습니다. 운영 매니저에게 요청해 주세요.
